# Sito_Mio

## Dove mettere il codice del tuo sito

Questo repository è strutturato per ospitare il tuo sito web. Ecco dove devi mettere i tuoi file:

### Struttura delle cartelle

```
Sito_Mio/
├── index.html          # Pagina principale del sito (HOME)
├── css/                # Metti qui tutti i file CSS
│   └── style.css       # Foglio di stile principale
├── js/                 # Metti qui tutti i file JavaScript
│   └── script.js       # File JavaScript principale
└── images/             # Metti qui tutte le immagini
    └── (le tue immagini)
```

### Come aggiungere il tuo codice

1. **File HTML**: 
   - Il file principale `index.html` è già presente nella root del progetto
   - Puoi modificarlo o sostituirlo con il tuo codice HTML
   - Aggiungi altre pagine HTML nella root (es: `about.html`, `contact.html`)

2. **File CSS**:
   - Metti tutti i tuoi file `.css` nella cartella `css/`
   - Il file `style.css` è già collegato all'index.html
   - Aggiungi altri file CSS se necessario e collegali nell'HTML

3. **File JavaScript**:
   - Metti tutti i tuoi file `.js` nella cartella `js/`
   - Il file `script.js` è già collegato all'index.html
   - Aggiungi altri file JavaScript se necessario

4. **Immagini e media**:
   - Metti tutte le immagini nella cartella `images/`
   - Puoi creare sottocartelle per organizzare meglio (es: `images/icons/`, `images/photos/`)

### Come visualizzare il sito

Apri il file `index.html` con il tuo browser web per vedere il sito in azione.

### Note

- I file di esempio forniti sono un punto di partenza - puoi modificarli o sostituirli completamente con il tuo codice
- Mantieni questa struttura organizzata per facilitare la manutenzione del sito
