# Image Directory

This directory should contain the following images for the website:

## Required Images:

1. **logo.png** - Company logo
2. **image.png** - CNSI text logo
3. **image-scopridipiu.png** - Image for "Scavi e movimento terra" service
4. **image-scopridipiu1.png** - Image for "Demolizioni" service
5. **image-scopridipiu2.png** - Image for "Trasporto e fornitura materiali edili" service
6. **image-noleggio.png** - Image for "Noleggio cassoni scarrabili" service
7. **image-deposito.png** - Image for "Deposito materiali" service
8. **image-facchinaggio.png** - Image for "Facchinaggio e logistica" service

## Image Specifications:

- Service card images should be at least 400x180 pixels
- Logo images should be PNG format with transparent background
- Service images should have aspect ratio suitable for 180px height display
